# 21 — Design System — Vantrilex Next-Gen Agentic Workbench & Launcher

## Purpose

The strict visual standard for every rendered surface.

## Status

DESIGN.md is law. Tokens live in `src/design/tokens.ts`; hex values are
never inlined in components.

## Schema

### Tokens

Warm-cream canvas `#faf9f5`, coral primary `#cc785c` (active `#a9583e`),
ink `#141413`, dark surface `#181715`. Serif display (Copernicus/Tiempos,
weight 400, negative tracking), StyreneB/Inter body, JetBrains Mono code.
Radii 8/12/16/pill, 32px card padding, 96px section rhythm.

### Rules

Cream canvas anchors every page; coral marks CTAs and callouts; dark
surfaces carry product chrome. No cool grays, no pure-white canvas, no
bold serif, no cyan accents in app UI.
